# CurrentIQ — AI Current Affairs Engine

AI-powered current affairs platform for Indian competitive exams (UPSC, NDA, CDS, AFCAT, SSC, GATE).

## Powered by Amazon Nova 2 Lite via AWS Bedrock

## Features
- Daily Digest — exam-specific news analysis
- MCQ Generator — exam-pattern questions from any topic
- Answer Evaluator — UPSC Mains scoring with feedback

## Tech Stack
- Backend: Python FastAPI on AWS App Runner
- AI: Amazon Nova 2 Lite via Amazon Bedrock
- News: PIB, The Hindu, BBC India, Economic Times RSS feeds
- Frontend: React + Vite on AWS Amplify
